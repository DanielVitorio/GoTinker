# Go Tinker

Go Tinker — настольная среда для Windows, запускающая PHP-код внутри проекта Laravel. Включает контекстные подсказки, сниппеты и коллекции, историю запусков, терминал в стиле Cmder и локальное хранилище SQLite.

## Сборка

Установите Go 1.23 или новее и запустите `.uild.ps1` в PowerShell. Приложение появится в `dist/GoTinker.exe`.

## Использование

Выберите проект Laravel с файлом `artisan` и запускайте код сочетанием **Ctrl+Enter**. Если выделить фрагмент, выполнится только он. Для сниппетов доступны папки и заметки, импорт и экспорт коллекций Postman и PHP-файлов. Терминал поддерживает несколько сеансов проектов.

## Языки

Нажмите на флаг в верхней панели, чтобы выбрать русский, английский, бразильский португальский, японский, упрощённый китайский или испанский. Переводы интерфейса и SVG-флаги находятся в `app/backend/web/lang/`, по одному JSON-файлу на язык.
