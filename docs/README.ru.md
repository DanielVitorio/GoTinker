# Go Tinker

Go Tinker — настольное приложение для Windows, которое выполняет PHP-код внутри проектов Laravel. В нём есть редактор кода с автодополнением на основе проекта, коллекции сохранённых запросов, окружения с переменными, история выполнений, встроенный терминал Cmder и локальное хранилище SQLite.

## Сборка

Cmder подключён как Git-подмодуль в `submodules\cmder`, поэтому клонируйте репозиторий с параметром `--recurse-submodules`:

```powershell
git clone --recurse-submodules <url-репозитория>
```

Если репозиторий уже клонирован без него, выполните `git submodule update --init --recursive`. Затем установите Go 1.23 или новее и 7-Zip и запустите `.\build.ps1` в PowerShell. Результат — `dist\GoTinker.exe` вместе с папкой `dist\cmder`.

## Использование

Выберите проект Laravel с файлом `artisan` и выполняйте код сочетанием **Ctrl+Enter**; если выделить фрагмент, выполнится только он. Сохраняйте запросы в коллекции через **Ctrl+S**, добавляйте переменные на вкладке **Переменные** (ключ `userId` становится `$userId`) и используйте значения окружения в коде как `{{name}}`. Каждое выполнение сохраняется в **Истории**. Коллекции и окружения можно импортировать и экспортировать в JSON, а также импортировать файлы `.php`.

Ваши данные хранятся в `%APPDATA%\GoTinker\gotinker.sqlite`.

## Языки

Откройте **Настройки** (значок шестерёнки в правом верхнем углу), чтобы выбрать бразильский португальский, английский, испанский, японский, русский или упрощённый китайский. Переводы хранятся в `app/backend/web/lang/`, по одному JSON-файлу на язык.

Полное руководство — в [основном README](../README.md).
