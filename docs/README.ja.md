# Go Tinker

Go Tinker は、Laravel プロジェクト内で PHP コードを実行する Windows デスクトップ環境です。プロジェクト対応の補完、スニペットとコレクション、実行履歴、Cmder をイメージしたターミナル、ローカル SQLite 保存に対応します。

## ビルド

Go 1.23 以降をインストールし、PowerShell で `.uild.ps1` を実行します。実行ファイルは `dist/GoTinker.exe` に作成されます。

## 使用方法

`artisan` を含む Laravel プロジェクトを選択し、**Ctrl+Enter** でコードを実行します。コードを選択すると選択範囲だけを実行します。スニペットにはフォルダーとメモを追加でき、Postman コレクションや PHP ファイルをインポート、エクスポートできます。ターミナルは複数のプロジェクトセッションを保持します。
